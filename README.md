# 📱 Photo Galaxy for Android

스마트폰 안의 사진들을 **방사형 트리(폴더별 · 연·월별 · 일별) + 멀티터치 시맨틱 줌**으로 탐색하는 안드로이드 앱입니다.

## 📲 APK 바로 다운로드 (스마트폰 설치용)
👉 **[PhotoGalaxy.apk 다운로드](https://github.com/HSH88888/photo-galaxy-android/raw/main/PhotoGalaxy.apk)**

1. 스마트폰 브라우저에서 위 링크를 눌러 `PhotoGalaxy.apk` 파일을 내려받습니다.
2. 다운로드된 파일을 탭해 설치하고, 첫 실행 시 **사진 및 동영상 접근 권한**을 허용합니다.

## ✨ 주요 기능
- **분류 기준 전환 (`폴더별` | `연·월별` | `일별`)**:
  - `DCIM/Camera`처럼 한 폴더에 수천~수만 장이 몰려 있어도 **연·월별 / 일별** 모드로 촬영 시기별 은하수 트리를 자동 구성합니다.
- **특정 폴더(하위 폴더 포함) 선택 (`📁 폴더`)**:
  - 기기 내 사진 폴더별 장수를 확인하고 원하는 상위 폴더만 골라 볼 수 있습니다.
- **대형 폴더 고속 렌더링 (`🖼️ 130장` 설정)**:
  - 15,000장이 들어 있는 폴더도 버벅임 없이 탐색하도록, 화면 내 노출 사진이 **130장 이하**(슬라이더로 `20~500장` 조절 가능)일 때만 썸네일을 로드합니다.
- **멀티터치 제스처**:
  - **두 손가락 핀치 줌**: 확대/축소 및 이동
  - **한 손가락 드래그**: 지도 이동
  - **탭 / 더블 탭**: 폴더·연도 줌인, 사진 전체화면 보기, 빠른 확대
  - **전체화면 뷰어**: 좌·우 스와이프로 이전/다음 사진 넘기기, 아래로 스와이프 또는 뒤로가기 버튼으로 닫기, `원본` 탭 시 휴대폰 기본 갤러리 연동

## 🛠️ 빌드 방법
```bash
./gradlew assembleRelease
```
